# Marketly — интернет-магазин с сервером и настоящей базой данных

Учебный проект для задания по веб-программированию. В проекте используются HTML, CSS, JavaScript, Fetch API, сервер Node.js и локальная база данных SQLite.

## Что реализовано

- Каталог из 12 товаров, хранящийся в SQLite и загружаемый с сервера через `GET /api/products`.
- Поиск, фильтрация по категории и диапазону цен, сортировка.
- Подробная карточка товара, корзина, избранное и сохранение корзины в браузере через `localStorage`.
- Оформление заказа через `POST /api/orders`; данные заказа и его позиции сохраняются в таблицах SQLite.
- Повторная серверная проверка данных и остатка товаров.
- Сервер сам считает стоимость по ценам из базы, рассчитывает доставку и уменьшает остатки в одной транзакции.
- Подписка на рассылку через `POST /api/newsletter`, email записывается в SQLite.
- Адаптивный интерфейс и демонстрационные иллюстрации товаров.

> Это учебный магазин: настоящие платежи не принимаются, доставка не подключена. Для тестирования используйте вымышленные данные.

## Запуск в Windows

### Вариант 1 — проще всего

1. Установите **Node.js 22.5.0 или новее** с официального сайта: https://nodejs.org/.
2. Распакуйте архив целиком в отдельную папку.
3. Откройте папку `marketly-server-db`.
4. Дважды щёлкните по `start.bat`.
5. Когда в окне появится сообщение `Marketly запущен: http://localhost:3000`, откройте этот адрес в браузере.
6. Не закрывайте чёрное окно терминала, пока пользуетесь магазином. Для остановки нажмите `Ctrl+C`.

### Вариант 2 — через VS Code

1. Откройте в VS Code именно папку проекта, где находятся `package.json` и `server.js`.
2. Выберите **Terminal → New Terminal**.
3. Убедитесь, что терминал находится в этой папке, и выполните:

   ```bash
   npm start
   ```

4. Откройте в браузере `http://localhost:3000`.

**Важно:** не открывайте `index.html` двойным щелчком. Запускайте сайт через сервер, иначе запросы Fetch API к базе данных работать не будут.

В этой версии нет внешних npm-зависимостей: сервер использует встроенный модуль `node:sqlite`, поэтому команда `npm install` не нужна. Требуется Node.js **22.5.0 или новее**.

## Как проверить работу сервера и базы

- `http://localhost:3000/api/health` — статус сервера и базы данных.
- `http://localhost:3000/api/products` — каталог, который сервер прочитал из SQLite и вернул в формате JSON.
- Оформите пробный заказ на сайте — номер заказа появится в окне подтверждения и запись будет сохранена в SQLite.

После первого запуска автоматически создаётся файл `data/marketly.sqlite` и таблицы. База сохраняется между перезапусками: новые заказы и обновлённые остатки не пропадают.

## Структура проекта

```text
marketly-server-db/
├── index.html              # HTML-структура магазина
├── styles.css              # стили и адаптивная вёрстка
├── app.js                  # клиентский JavaScript и Fetch API
├── server.js               # HTTP-сервер и REST API
├── package.json            # команда запуска
├── start.bat               # запуск в Windows двойным щелчком
├── database/
│   └── schema.sql          # SQL-схема таблиц
├── assets/
│   ├── favicon.svg
│   └── products/           # иллюстрации 12 товаров
└── data/
    └── marketly.sqlite     # создаётся автоматически при запуске
```

## Таблицы базы данных

- `products` — товары, цены, категории, рейтинги, описания и остатки.
- `orders` — номер, контактные данные, адрес доставки, сумма, способ оплаты и статус заказа.
- `order_items` — позиции каждого заказа и цены на момент оформления.
- `newsletter_subscribers` — email подписчиков.

Чтобы посмотреть содержимое базы, остановите сервер и откройте файл `data/marketly.sqlite` в программе DB Browser for SQLite. Не делитесь реальной базой данных: в заказах могут храниться контактные данные. Для учебной демонстрации используйте вымышленные данные.

## API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/health` | Проверить сервер |
| `GET` | `/api/products` | Получить товары из SQLite |
| `POST` | `/api/orders` | Проверить и сохранить заказ, уменьшить остатки |
| `POST` | `/api/newsletter` | Сохранить email подписчика |

## Демонстрация преподавателю

1. Запустите сервер и откройте `http://localhost:3000`.
2. Покажите 12 товаров, поиск, фильтры и сортировку.
3. Добавьте несколько товаров в корзину и обновите страницу — корзина сохранится в браузере.
4. Оформите заказ с вымышленными данными.
5. Покажите номер заказа и откройте `http://localhost:3000/api/products`.
6. При необходимости откройте `data/marketly.sqlite` в DB Browser for SQLite и покажите таблицы `products`, `orders` и `order_items`.

В проекте нет административной панели, реального эквайринга или интеграции с перевозчиком.
